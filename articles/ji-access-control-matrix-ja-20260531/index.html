The Self as an Access Control Matrix

I
$$D = P_\phi(W)$$

データは世界そのものではない。センサー、事前分布、設計者を通した射影である。

II
$$Z = C_\theta(D)$$

圧縮は、選ばれた差異を保存する。大事な差異だけが残る。

III
$$O_K(W) = \bigcap_{a \in K} C_a(P_a(W))$$

カテゴリ客観とは、そのカテゴリの圧縮器を通してなお残るもの。

IV
$$S_{t+1} = F(S_t,\, \Pi_B(X_t))$$

境界はただの壁ではない。次の状態へ何を通すかを選ぶ。

編集権限表

誰がどこへ書き込めるか
$$\mathcal{A} : \text{Source} \times \text{Target} \to \text{Permission}$$
Source 習慣 価値 道徳 欲望 管理
parent write write - - -
friend - write - - -

ad deny deny - deny -

自己とは、編集権そのものではない。誰に、何を、どこまで編集させるかを配る規則である。

$$\operatorname{cap}(s) = \{(r,p) \mid \mathcal{A}(s,r)=p\}$$

Capability は、主体側から見た権限である。

$$\operatorname{acl}(r) = \{(s,p) \mid \mathcal{A}(s,r)=p\}$$

ACL は、対象側から見た権限である。

主観 → 知性 は、まだ開いたままにしておく。
