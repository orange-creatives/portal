The Self as an Access Control Matrix

Projection, compression, category objectivity, instinct, boundary, memory, and self-editing compressed into a small set of formulas.

World Projection Compression Boundary Memory Future Self Access Control Matrix

Projection

$$D = P_\phi(W)$$

Data is a projection of the world.

$$\phi \in \Phi$$

Every projection has a designer, a sensor, or a prior.

Compression

$$Z = C_\theta(D)$$

Compression preserves selected differences.

$$\theta = V(A, G, H)$$

The compression rule depends on agent, goal, and history.

$$\Delta_i \in Z \quad \Longleftrightarrow \quad V(\Delta_i \mid A, G, H) \ge \tau$$

A difference survives when it matters enough.

Evaluation Words

$$\text{``Good''} = \text{good for whom?}$$
$$\text{``Natural''} = \text{natural under which prior?}$$
$$\text{``Objective''} = \text{stable across which compressors?}$$

Evaluation words hide their subject.

Category Objectivity

$$O_K(W) = \bigcap_{a \in K} C_a(P_a(W))$$

Objectivity for a category is what survives across its compressors.

$$K \in \{\text{person}, \text{human}, \text{animal}, \text{living system}\}$$

Categories share histories of contact with physical reality.

$$H_K \longrightarrow C_K \longrightarrow O_K$$

A shared evolutionary history shapes a shared compression.

Instinct

$$I_s = C_s(H_s, W)$$

Instinct is compressed survival history.

$$I_s : W \mapsto R$$

Instinct maps world-patterns to responses.

$$I_s \neq \text{command written from outside}$$

It is not merely an imposed command.

$$I_s = \text{scar} + \text{battle record} + \text{trophy}$$

It is a trace of having survived.

Boundary

$$B \neq \text{container wall}$$

A boundary is not just a wall.

$$S_{t+1} = F(S_t,\, \Pi_B(X_t))$$

A boundary filters what enters the next state.

$$\text{self-maintenance} \longrightarrow B$$

The boundary emerges from self-maintenance.

Memory Layer

$$M_t = \Pi(S_t, X_t)$$

Memory selects what may be written.

$$S_{t+1} = U(S_t, M_t)$$

The next state is edited by selected memory.

$$M_t \neq \text{log}(X_t)$$

Memory is not a raw log.

Future Self

$$\hat{S}_{t+1} = Q(S_t)$$

The agent contains a model of its future self.

$$a_t = \pi(S_t, \hat{S}_{t+1}, E_t)$$

Action depends on the editable future.

$$E_t = \text{editable region model}$$

Freedom appears as modeled editability.

Access Control Matrix

$$\mathcal{A} : \text{Source} \times \text{Target} \to \text{Permission}$$

The self is an access control matrix.

$$\mathcal{A}(s, r) \in \{\text{deny}, \text{read}, \text{write}, \text{admin}\}$$

It decides who may write where.

Source Habit Value Moral Desire Admin

$$S_{t+1} = U\left(S_t,\, \{x \mid \mathcal{A}(\operatorname{src}(x), \operatorname{target}(x)) \ge \text{write}\} \right)$$

The future self is updated only by permitted writes.

$$\text{Self} \neq \text{edit right}$$
$$\text{Self} = \text{rule assigning edit rights}$$

The self is not the edit right itself.

It is the rule that distributes edit rights.

Capability View

$$\operatorname{cap}(s) = \{(r, p) \mid \mathcal{A}(s,r)=p\}$$

Capability is the subject-side view.

$$\operatorname{acl}(r) = \{(s, p) \mid \mathcal{A}(s,r)=p\}$$

ACL is the object-side view.

$$\text{Subjectivity} \longrightarrow \text{Intelligence}$$

The path from subjectivity to intelligence is left open.
